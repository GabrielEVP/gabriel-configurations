# Herdr

Personal configuration for the Herdr app (`~/.config/herdr-app`).
Herdr reads this folder live: layouts, keys, mods and themes are reloaded while it runs.

## What is versioned here

| Path | Content |
|---|---|
| `settings.json` | App preferences (zoom, font size, sounds, contrast) |
| `keys.json` | Global and terminal keybindings |
| `shared.json` | Layout selection, panel layout, per-space colors |
| `view.json` | Last active space/tab and recent folders |
| `window.json` | Window state and geometry |
| `installed.json` | Manifest of mods installed by the app with their hashes |
| `layouts/` | Custom layouts (`*.json` + their `*.svg`) |
| `themes/` | Custom themes |
| `mods/` | Mod source files (`*.js`, `*.json`, `*.svg`) |

## What is NOT versioned

| Path | Reason |
|---|---|
| `AGENTS.md`, `herdr.d.ts`, `gpui-kit.d.ts`, `jsconfig.json` | Regenerated by the app on every start |
| `frame/`, `icons/`, `data/` | App UI assets shipped with the binary |
| `telemetry/`, `seen.json`, `update-notes*.json`, `*.sock` | Runtime state |
| `layouts/.state/` | Runtime layout state |
| `mods/*/*.patched` | Local patch backups |
| `mods/win98/` | Downloaded asset-heavy mod (fonts, sounds, images) |
| `mods/*/gpui-kit.d.ts` | 810 KB type definition regenerated by the app |

## Restore

Copy the folders and JSON files into `~/.config/herdr-app`, then start the app.
The app regenerates the excluded files on its own.
